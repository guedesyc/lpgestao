Button — the primary call-to-action control, in brand navy or teal.

```jsx
<Button variant="primary" size="md" onClick={() => {}}>Fale conosco</Button>
```

Variants: `primary` (navy fill), `secondary` (teal fill), `outline` (navy border, transparent), `ghost` (text-only). Sizes: `sm`, `md`, `lg`. Pass `disabled` to gray it out; pass `icon` for a leading icon node.
