Card — soft-shadow content container, the base building block for grids and lists.

```jsx
<Card eyebrow="Serviço" title="Restaurantes Corporativos" footer={<Button variant="ghost">Saiba mais</Button>}>
  Refeições sob medida para o seu time, todos os dias.
</Card>
```

`elevated` swaps the resting shadow for the raised/hover shadow.
